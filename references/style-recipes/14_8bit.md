# 14_8bit · 1985 8-bit pixel game

## Pipeline
1. **The whole picture is drawn on a 240×135 low-resolution canvas** (1 low-res pixel = 8 screen pixels; the original's pixel blocks measure exactly 8px), then upscaled 8× in a single `drawImage` with `imageSmoothingEnabled=false`.
2. **Background drawn per pixel with `fillRect`** (cached `8b_bg`): cross-dot wall = 3×3 crosses on a 6px grid, alternate rows offset 3px; wooden floor strip y=106–113, a black seam every 24px; bricks 16×6 + 1px seams, alternate rows offset 8, with a row of beige highlight (`#fbe2a6`) along the top and left edges. The sky in the window uses 3 blues (`#0856ef / #47c4f8 / #aae9fb`), with ±0.05 bands at the boundaries dithered as a `(x+y)%2` checkerboard — the only way the NES does gradients.
3. **Characters = RIG paths scaled down to low resolution and filled → spriteize**: each part on its own layer (far arm / body and legs / hair / face / bangs / near arm; cat body / cat head); for each layer:
   - `getImageData` → alpha < 110 becomes fully transparent (removing anti-aliasing) → the rest quantized to a 14-color character palette (nearest color);
   - the outer contour gets a 1px black edge (any transparent pixel with an opaque pixel among its 4 neighbors is painted black).
   **Outlining per layer is the key**: outlining the whole thing once smears hair/face/arms into one blob; outlining each part separately gives the inner contours of an NES sprite.
4. **Facial features are all placed per pixel** (eyes 1×2 black + brow, cat eyes 2×2 black + 1 white highlight at top left, pink nose 1px, blush 2×1), positioned with RIG anchors `/8` rounded.
5. **The mug doesn't use RIG.drawCup**: an anti-aliased path scaled to 6px wide blurs, so draw a 6×5 white mug + two red stripes + a 3px handle directly at low resolution, following `G.cup`.
6. **HUD drawn at full resolution**: `PressStart2P` 48px (1 font pixel = 6 screen pixels; 64px is too wide and makes WORLD 1-1 collide with the apple icon), 8px black drop shadow; the cat-head/heart/apple icons are string bitmaps, 8×8 per cell.

## Jeans
RIG.girl wears a long skirt; the 8-bit version draws blue trousers with two `RIG.taper` segments (hip `G.hipSeat` → knee (1222,724) → ankle (1214,872), widths 92/76/56), the far leg one shade darker `#0838a8` and set back 26px; white sneakers + one red stripe.

## Small loops (on screen only about 0.23s ≈ 11 visible frames; all done as stepped animation)
- Cat tail: a 15fps four-pose loop `[-0.55, 0, 0.55, 0]` (RIG.cat's tail parameter) — pixel animation's "a few drawings alternating".
- HUD hearts blinking: lt 0.16–0.23 (≈ frame 630), switching every 2 frames: full hearts turn white, empty hearts turn full red.
- Potted plant shaking: within the same window the leaves shift by whole pixels `[0,1,0,-1]`.
- Question block pops out a coin: lt 0.06–0.22, a half-sine up 9px and back down.
- Clouds outside the window move 1px left every 2 frames; pixel steam is three columns of 1×2 dots, moving up 1px per frame at 30fps on a 6px loop.

## Pitfalls we hit
- The top of RIG's cat head reaches y≈535 and covers the windowsill (the window goes down to y=590). This is the shared skeleton position and wasn't moved; the 8-bit black outlines make the overlap more noticeable, but the transitions depend on the standard composition, so it stays.
- `spriteize` reads non-premultiplied RGBA; don't divide by alpha again.
- Performance: hot frames 2.5–6ms, cold start 11ms.
